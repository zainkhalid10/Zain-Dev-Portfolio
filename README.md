# Zain Dev Portfolio

A modern and responsive developer portfolio website built to showcase my projects, technical skills, achievements, and experience in AI, full-stack development, and software engineering.

## 🚀 Overview

This portfolio serves as a central platform for presenting my:

* Featured projects and case studies
* Technical skills and tech stack
* Experience in AI and full-stack development
* Resume and contact information
* GitHub and social links

The website is designed with a clean UI/UX, responsive layouts, smooth navigation, and performance optimization to provide an engaging user experience across all devices.

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone https://github.com/zainkhalid10/Zain-Dev-Portfolio.git
cd Zain-Dev-Portfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open your browser:

```bash
http://localhost:3000
```
